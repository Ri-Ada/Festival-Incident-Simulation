Festival Incident Simulation 

Simple object-oriented programming project written in Python.

This project simulates different types of emergency incidents and models how they evolve over time. Each incident has its own resolution logic, escalation behaviour, and probability of success.

The system currently includes:
- Fires
- Drug overdoses
- Drunk fights
- Riots

The project incorporates:
- inheritance
- abstraction
- polymorphism
- encapsulation
- factory pattern design

Some incidents are also able to transform into more severe situations during the simulation (for example, a drunk fight escalating into a riot).

Features:
- Abstract base class
- Individual behaviour for each incident type
- Randomized simulation outcomes
- Escalation mechanics
- Incident transformation system
- Simulation engine for processing incidents
- Factory class for generating random incidents
